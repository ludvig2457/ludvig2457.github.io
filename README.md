## 🚀 Проекты

### SuperLauncherMC

Лаунчер для Minecraft, который **не тормозит**. Портативный, лёгкий, с поддержкой всех версий.

- **Вес:** минимальный (один `.exe`)
- **Запуск:** мгновенный
- **Функции:** автоустановка Java, поддержка Forge, Fabric, NeoForge, Quilt, моды в один клик
- **Репозитории:** [SuperLauncherMC](https://github.com/Ludvig2457Ultra/SuperLauncherMC), [Native](https://github.com/Ludvig2457Ultra/SuperLauncherMCNative), [Ultra](https://github.com/Ludvig2457Ultra/SuperLauncherMCUltra), [CLI](https://github.com/Ludvig2457Ultra/SuperLauncherMC-CLI), [Android](https://github.com/Ludvig2457Ultra/SuperLauncherMCandroid), [Linux](https://github.com/Ludvig2457Ultra/SuperLauncherMC-for-linux)

### LudvigOS

**Своя операционная система на C++ и ассемблере.**

- **Цель:** максимальный контроль над железом, своя проверка драйверов на безопасность
- **Архитектура:** x86_64, монолитное ядро, UEFI-загрузчик
- **Репозиторий:** [LudvigOS](https://github.com/Ludvig2457Ultra/LudvigOS)

### LudvigEditor

**Быстрый редактор кода.** Лёгкий, открытый, без лишнего.

- **Репозиторий:** [LudvigEditor](https://github.com/Ludvig2457Ultra/LudvigEditor)

## 🎮 Моды для Minecraft

### Scale Of Tools

**Клиентский мод, который предупреждает, когда инструмент вот-вот сломается.**

- **Что делает:** показывает уведомление в action bar, когда прочность падает до 10
- **Фишки:** инструмент сжимается при износе, палки остаются на земле после поломки
- **Версии:** 1.20.1, 1.20.4, 1.21.1, 1.21.4
- **Загрузчики:** Fabric, Forge, NeoForge, Quilt
- **Скачать:** [CurseForge](https://www.curseforge.com/minecraft/mc-mods/scale-of-tools), [Modrinth](https://modrinth.com/mod/scale-of-tools)
- **Репозиторий:** [Scale-Of-Tools](https://github.com/Ludvig2457Ultra/Scale-Of-Tools)
