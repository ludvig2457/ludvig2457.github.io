FAQ

Частые вопросы

Почему лаунчер такой маленький?
Потому что он не тянет за собой JVM, не включает Electron или Qt, не использует внешние библиотеки. Только C++, Assembler и прямые вызовы WinAPI.
Нужна ли Java?
Нет. Лаунчер сам скачает нужную версию Java под конкретную версию Minecraft. Тебе не нужно ничего ставить вручную.
Какие версии Minecraft поддерживаются?
Все — от Alpha до последних релизов. Лаунчер использует официальный список версий Minecraft и автоматически подбирает нужную Java.
Какие загрузчики модов поддерживаются?
Forge, Fabric, NeoForge, Quilt и OptiFine. Все ставятся автоматически в пару кликов.
Можно ли запустить на Windows XP?
Да. Есть отдельная сборка SuperLauncherNative_xp.exe, собранная специально для Windows XP. Она весит те же 260 КБ и работает на старом железе.
Лаунчер бесплатный?
Да, полностью бесплатный. Исходный код открыт на GitHub под лицензией GPLv3.
Можно ли играть без лицензии?
Да, поддерживается офлайн-режим. Но для игры на официальных серверах потребуется лицензионный аккаунт.
Как обновить лаунчер?
У лаунчера есть встроенный авто-апдейтер. Он сам проверяет обновления при запуске и предлагает установить новую версию.
