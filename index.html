02 — Operating System

LudvigOS. Два мегабайта свободы.

Своё ядро на Multiboot, VGA-драйвер, GUI с мышью, shell с пакетными менеджерами. Всё на C++ и Assembly. Всё своё.

02

Собственное ядро

C++ с поддержкой Multiboot. Управление памятью, VGA-драйвер, обработка прерываний без внешних библиотек.

GUI

Рабочий десктоп с мышью и клавиатурой через порты 0x60/0x64. Окна, курсор, реакция на ввод.

Shell + LUR/LURE

Командная оболочка с neofetch, пакетными менеджерами LUR и LURE, игровыми командами.

2 МБ ОЗУ. Серьёзно.

Экстремально лёгкая система. Работает на самом старом железе. Загружается через GRUB2 из ISO. Идеально для QEMU и ретро-машин.

03 — Minecraft Mods

Scale Of Tools. Спасает инструменты.

Клиентский мод. Предупреждает, когда инструмент вот-вот сломается. 4 загрузчика, 4 версии, 80+ скачиваний на CurseForge.
