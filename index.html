01 — Minecraft Launcher

SuperLauncher

Minecraft лаунчер с автоматической установкой модов и управлением серверами

Моды и сборки

Modrinth API — установка модпаков в один клик. Поддержка Forge, Fabric, NeoForge и OptiFine с авто-установкой.

Управление серверами

Создание локальных серверов, плагины из Modrinth, поддержка Bukkit/Spigot/Paper, авто-обновления.

Современный интерфейс

Светлая и тёмная темы, анимированные переходы, Discord Rich Presence.

02 — Operating System

LudvigOS

Собственная операционная система на C++ с графическим интерфейсом

Собственное ядро

Полноценное ядро на C++ с поддержкой Multiboot, VGA-драйвером и управлением памятью.

Графический интерфейс

Рабочий десктоп с поддержкой мыши и клавиатуры через порты 0x60/0x64.

Командная оболочка

Терминал с neofetch, LUR/LURE пакетными менеджерами и игровыми командами.

Всего 2 МБ ОЗУ

Экстремально лёгкая ОС — работает даже на самых старых машинах.

Ядро C++ Multiboot
Видеорежим VGA 80×25

04 — About

О проекте Ludvig2457

Ludvig2457 — разработчик с открытым исходным кодом. Создаёт инструменты для геймеров и энтузиастов: Minecraft лаунчер с полной поддержкой модов и собственную операционную систему.
